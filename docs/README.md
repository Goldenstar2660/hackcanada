## Purpose

This folder contains architecture, operations, and decision documentation.

Use this area for ADRs, deployment notes, operating procedures, and longer-form explanations that support the product spec without replacing it.

## Ownership Boundary

* Put architecture and operational documents here
* Keep the product spec in `spec/` as the source of truth
* Use documentation to explain implementation choices and runbooks, not to redefine scope
